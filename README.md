## One command installation setup
The-All-Blue `install-all.sh` script is set to `lazy install` that means it will install all the necessery packages and put them to their places. **This is a personal Dots cause i dont want to do all this manually next time.**

## Intro
>The-All-Blue is FULLY customizable `Arch` `Hyprland(0.55.3)` .Dots Repo. It has custom **Flavour**, **Theme** & **Wallpaper Switcher via Rofi**. I can choose which *Flavour* I want in Rofis preview. 
>

## Now, what are Flavours? 

>Flavours are alternative to theme switcher. They are the same thing. I just named my version of them **Flavours** Just cause i can🙂.
>
>Anyways, Each Flavour has there own kinds of desktop styles, animation, background and vibe. When you change themes it changes the whole desktop **GTK theme** , **cursor**, **Waybar layout**, **window layout**, **animation**, **notification or swaync**, **Rofi**, **powermenu**, **swayosd**, **screensaver video**, **hyprlock**, **startup intro music** .Also made my own version of screensaver but mine plays videos, no ascii. But vscode, nvim, chrome dosnt change, i targeted few cause i dont have that much time to do all that.And it doesnt matter. 
>
>I am using pywal16 to inject wallpapers colors to all Application and desktop to match the vibe. In themes there are Default, i3, anime, Gruvbox, Everforest, Catpuchhin etc.
>
>## Flavour Example:
>>**Default-Flavour:** As the name suggests on your 1st install if you dont change the install script then Default Flavour will be set. It has besic animation , gaps, blurs, notification + Notification sound, Start up music, custom cursor, Screen-saver video and everything is changeable.
>
>>**i3-Flavour:** Its not the 13 window manager, it is Hyprland set like i3. Because i3 was my 1st tilling window manager hence i like it. So i made i3 look alike window not rounded corners, no blurs or transparency, no gaps, no animation, no notification sound, the waybar is set to look my og i3 blocks that was my 1st ever rice. So i recreated it and still using rofi but set to look like dmenu. I use i3 flavour when i work on my projects cause then i dont want any distractions.
